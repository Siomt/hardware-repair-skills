# 整机与启动故障

## 分类与记录

先记录型号、板号、配置、变更经过、外接设备及可用的已知良好替换件，观察充电灯、电源灯、风扇、蜂鸣/闪灯代码、画面以及是否进入 BIOS。询问是首次出现还是偶发、冷机或负载下出现。检查型号对应厂商文档，代码必须与机型匹配。

- 无电：没有明确供电迹象。优先排外部电源、线、接口、电源开关；笔记本转笔记本供电流程，台式机查外部供电、电源输出与接口。
- 通电不自检：有灯或风扇并不代表 POST 成功。记录代码，移除非必要外设并以厂商允许的最小配置排查；断电后复位可拆卸内存及供电连接器，逐项改变并记录。焊接内存或不熟悉的连接器不强拆。
- 自检可能成功但无画面：区分显示器、输入源、线缆、接口和显卡。通过已知良好的显示器/线缆交叉测试；核实主板视频输出需要兼容的集显。笔记本查内外屏及背光。风扇转不证明进入系统。
- 能显示自检但不启动系统：记下错误，在 BIOS 检查磁盘是否识别；结合存储流程，优先保护数据。固件设置、重装或磁盘修复可能影响数据或 BitLocker，先核实备份、恢复密钥及原设置。

## 不稳定、重启、蓝屏

记录触发时机、温度、错误代码、近期硬件/驱动变化、供电配置。先检查散热、线缆和系统事件，再按单一变量测试内存、存储、显卡与供电；用厂商诊断或系统测试时说明可能造成负载或写入。不要将蓝屏代码直接等同某个硬件已坏。异常气味、火花或反复断电停止通电。

## 固件与验证

记录当前设置，依据型号文档评估恢复默认、清 CMOS 或更新固件的必要性、风险及恢复路径；不要先做破坏性重置。每次只更改一项，验证原故障场景、重启及相关功能，记录仍未覆盖的场景。
