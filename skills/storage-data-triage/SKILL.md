# 存储硬件与数据保护

## 共同规则
询问准确型号、症状、故障经过、已有读数、工具和操作经验；每次只给最有区分度的一项或少量检查，等待反馈。写明检查目的、设备状态、位置、操作、结果含义与下一步；不把线索当结论。没有对应型号资料时不编造引脚、测点或正常值，优先查原厂手册和数据手册。明确不确定性，记录故障与验证。

断开所有可安全隔离的电源和电池，验证无电后才用电阻、通断、二极管、电容档。市电及其电源内部、显示器高压、微波炉内部、燃气、压力及制冷回路不指导拆修、带电测量或绕过保护，应交专业人员；损坏或鼓包电池停止使用。严禁盲目注压、短接保险和保护。带电低压测量须确认测点、参考地、仪器额定值和操作者能力；条件不足则停。涉及数据优先保护原盘及备份。

## 分诊和检查
先问数据价值、备份、盘体型号、连接方式、掉盘/异响/摔落/进液及是否已反复通电。机械盘异响、进液或读取严重异常且数据重要时停止通电，建议专业恢复。不要格式化、初始化、重建阵列、修复文件系统、写入测试或拆开机械硬盘腔体。

盘稳定时核对供电、线缆、接口协议、BIOS 识别和只读健康数据；SMART 正常不能排除故障，未识别也可能是接口、供电或转接协议。更换线材/接口前断电，单次改变一项。数据重要且可读取时先评估镜像优先和独立目标，尊重 SSD TRIM、加密和介质状态；是否镜像或交专业服务取决于风险，不保证可恢复。记录识别状态、健康数据与处理历史。
