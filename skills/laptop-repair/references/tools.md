# 维修工具：选择、添置和使用

用户已有万用表、烙铁，也愿意根据实际需要购买其他工具。先问现有仪器型号、探头/附件、使用经验和预算是否影响当前步骤；根据故障选择最有区分度的方法。工具不是越多越好，说明现有工具的限制、仪器能测什么和不能证明什么，以及替代方案。未明确品牌或型号时不编造产品参数或价格，推荐购买具体型号前查询当前厂商规格、供货及价格。非必要时不要让用户先采购再进行所有排查。

## 按需求选择

- 放大镜或显微镜、照明：用于检查微小焊点、腐蚀、断线及板号。关注实际工作距离、倍率与图像质量，选择能在镜头下安全焊接的结构；照片清晰度仍影响判断。
- 温控烙铁、合适烙铁头、助焊剂、吸锡材料及必要时热风台：用于隔离、拆装和复焊。确认封装、热容量、焊盘结构及本人经验；多层板、BGA 和紧密元件可能需要预热设备和技能，并非增加温度即可处理。保护附近元件，控制通风和温度；不把加热或重流当成定位故障的手段。
- 可调直流稳压电源：在电路确定时用于观察输入电压及电流变化；确认正常工作电压、极性、接口、供电协议和仪器限流。电流显示要结合运行阶段及电源动态响应，不能将某个电流值作为通用故障码。限流不是防损保证；USB-C 供电可能需要协议协商，不可直接套用固定电压。
- 示波器：用于观察电源上电时序、时钟、复位、使能、纹波、短暂掉电及低速数据线波形。先确认信号测点与预期时序并查芯片数据手册；按目标信号频率、上升时间、幅度、通道数、采样率、存储深度、探头和接地方式评估需求。两通道通常有助比较供电与使能，但不要把它作为所有任务最低要求；高速接口可能需要更高带宽、低电容探头或专用设备。读到静态电压并不能证明时钟或高速信号正常。
- ESR 表、电容表或 LCR 表：用于辅助判断隔离后电容容量、等效串联电阻等；频率、电压、量程、容差、校准及是否允许在板测量都影响结果。在板并联路径及残压仍会干扰；ESR 正常不能排除全部故障。
- 热成像仪、热像手机附件或合适的非接触测温工具：用于安全供电条件下定位异常发热点，但热源可能是故障结果、正常工作元件或受邻件传热；需要结合供电轨和测量确认。不要为了看到发热而盲目加大电压、电流或进行长时间加热。
- BIOS 编程器及匹配夹具：仅在已确认芯片型号、电压、引脚、可靠数据来源和故障证据时考虑。先备份原始固件并验证重复读取一致，确认序列号、授权、密钥等个体数据及恢复方案；避免未经核实刷写和热插拔。未知条件或加密风险时先停。
- 其他：已知良好的适配器/内存/显示器、POST 卡、USB-C PD 测试仪、电子负载、逻辑分析仪，可根据接口及诊断目的使用。POST 卡未显示代码不证明某芯片故障；USB-C 测试工具必须支持目标协议、方向及功率。

## 可调电源与注压的区别

正常接口供电用于在已知规格内模拟适配器；对疑似短路供电轨注压是不同且风险更高的操作。只有确认电路拓扑、该轨允许上限、负载和隔离边界、极性、电流限制、接入点、测量方式及用户经验，并有对应板级资料时，才考虑提出具体注压方案；先解释损坏风险和替代方法。若任何关键信息不明，不提供猜测的注入电压或电流，不建议照搬网上固定值。对 CPU/GPU 核心、内存等低压轨尤其不可盲目注压。

## 示波器接地与测量安全

先核对示波器型号、供电、接地方式、探头额定值及手册。许多台式示波器普通探头的地夹与保护地相连；接到非地测点可能造成短路、损坏设备或触电。仅当明确待测设备的参考地与示波器地可安全相连，且测点电压处于仪器和探头额定范围，才在断电时连接；通电前复核接线。不得通过拔保护地或使用无依据的转接插头解决接地问题。测量非共地、悬浮、高侧或市电相关信号，需要正确额定、适合应用的差分/隔离探头和专业人员；没有合适设备和经验就停止。不要凭照片猜示波器地夹位置。探头衰减、示波器设置、补偿及带宽会改变波形；测量前记录通道、衰减、量程、时间基准和触发条件。

## 给用户的采购建议格式

只推荐当前故障真正需要的工具，按「现在就需要 / 可替代 / 后续再买」排序。每项说明：要解决的问题、必要规格及附件、能否先用现有设备替代、使用安全前提、预计价值；用户确定预算后，再查询当前可买到的具体型号并说明价格和来源。需要时可以分阶段配备，不假定最贵的就是最合适的。
