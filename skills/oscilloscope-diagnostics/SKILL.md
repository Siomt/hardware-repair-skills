# 示波器与波形分析

## 共同规则
询问准确型号、症状、故障经过、已有读数、工具和操作经验；每次只给最有区分度的一项或少量检查，等待反馈。写明检查目的、设备状态、位置、操作、结果含义与下一步；不把线索当结论。没有对应型号资料时不编造引脚、测点或正常值，优先查原厂手册和数据手册。明确不确定性，记录故障与验证。

断开所有可安全隔离的电源和电池，验证无电后才用电阻、通断、二极管、电容档。市电及其电源内部、显示器高压、微波炉内部、燃气、压力及制冷回路不指导拆修、带电测量或绕过保护，应交专业人员；损坏或鼓包电池停止使用。严禁盲目注压、短接保险和保护。带电低压测量须确认测点、参考地、仪器额定值和操作者能力；条件不足则停。涉及数据优先保护原盘及备份。

## 测量流程
先确定问题和需比较的具体信号，查芯片手册或图纸确认引脚、时序、参考地、幅度与信号频率；没有目标和对照时不要把任意波形判定为正常。核对带宽、采样率、通道、探头倍率和额定值；记录探头补偿、量程、时间基准和触发设置，再在操作者有能力且设备稳定的情况下测量。

多数台式示波器普通探头地夹连接保护地，接到非地测点可能短路、触电或损坏；先核查手册与待测设备共地关系，在断电时连接已确认的安全地，不拔保护地。非共地、高侧、市电或隔离要求的测量需要适当额定的差分/隔离探头和专业能力；条件不明则停止。波形异常还可能来自接地回路、探头负载或触发设置，比较参考和仪器误差，不以示波器读数单独断定芯片坏。参考[工具](references/tools.md)。
